# 🎬 Instagram Reel Downloader

Веб-приложение для скачивания Instagram reels с ограничением 2 в сутки.

**БЕЗ ТОКЕНА! БЕЗ БЭКЭНДА! 🔐**

---

## 🚀 Как использовать (Для пользователя)

### Единственное что нужно (В 1 клик!):
1. Открой: https://xopromo.github.io/telethon/
2. Вставь Instagram reel ссылку
3. Нажми "⬇️ Скачать"
4. **GitHub Issue создастся автоматически!** ✨
5. GitHub Actions **автоматически скачает видео** 🤖
6. Посмотри комментарий в Issue → ссылка на артефакт
7. Скачай видео из артефактов!

**ВСЕ ДЕЙСТВИЯ АВТОМАТИЧЕСКИЕ! НЕ НУЖНО НИЧЕГО ДЕЛАТЬ!** 🔐

---

## 🔧 Как работает (Технически)

```
Пользователь открывает форму
    ↓
Вставляет Instagram ссылку
    ↓
Нажимает "Скачать"
    ↓
Форма открывает GitHub Issue форму (pre-filled)
    ↓
Пользователь нажимает "Create issue"
    ↓
GitHub Actions видит новый Issue
    ↓
Workflow автоматически:
  1. Извлекает URL из Issue
  2. Проверяет rate limit (2 в сутки)
  3. Скачивает видео через yt-dlp
  4. Загружает в артефакты (7 дней)
  5. Добавляет комментарий с результатом
    ↓
Пользователь скачивает видео из артефактов!
```

---

## 📋 Лимиты

- **2 скачивания в сутки** (все пользователи вместе)
- Лимит обновляется каждый день в 00:00 UTC
- Логируется в `rate_limiter.json`
- Видео хранится 7 дней в артефактах

---

## 🔐 Безопасность

- ✅ **Никаких токенов у пользователя**
- ✅ **GitHub Actions используют встроенный GITHUB_TOKEN**
- ✅ **Все операции в GitHub (ничего не теряется)**
- ✅ **Cookies зашифрованы в GitHub Secrets**

## 🛠️ Для админа

### Первая настройка:
1. **Settings** → **Secrets and variables** → **Actions**
2. Добавь Secret `INSTAGRAM_COOKIES` (optional, для авторизации в Instagram)
3. **Settings** → **Pages** → выбери ветку `claude/stoic-davinci-JzEZb`, папка `/docs`
4. Готово! 🎉

### Без лимитов (только админ):
Коммит напрямую в репо автоматически использует GITHUB_TOKEN (встроенный токен GitHub Actions), и лимит не применяется для автоматических операций.
