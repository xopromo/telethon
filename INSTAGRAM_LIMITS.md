# Instagram Agent — Лимиты и Best Practices

## 📊 Текущие ограничения

### GitHub Actions (Бесплатный tier)
- **2000 минут/месяц**
- На видео ~3-5 минут
- **Максимум:** ~400-600 видео/месяц

### Instagram (главное узкое место)
- **Rate limiting:** 429 ошибки при частых запросах
- **Блокировка:** 1-24 часа за слишком частые скачивания
- **Риск бана:** высокий если 100+ видео/день

### AI API (Mistral, Gemini, Cerebras)
- Зависит от твоих лимитов
- Примерно 500 токенов на переписку описания

### Telegram
- **Размер видео:** макс 4GB (в агенте 2GB для безопасности)
- **Rate limit:** низкий риск

## ✅ Безопасные сценарии

| Сценарий | Частота | Видео/день | Риск | Примечание |
|----------|---------|-----------|------|-----------|
| **Тестирование** | Manual | 1-3 | 🟢 Низкий | Редкие ручные запуски |
| **Ежедневный** | Cron 6h | 4-5 | 🟢 Низкий | Добавлены delays |
| **Часто** | Cron 2h | 10-12 | 🟡 Средний | Может потребоваться 2FA |
| **Очень часто** | Cron 30m | 30+ | 🔴 Высокий | Высокий риск блокировки |

---

## 🛡️ Как мы защищаемся

### 1. Random delays между видео
```python
DELAY_BETWEEN_VIDEOS = (120, 300)  # 2-5 минут между видео
```
- Имитирует реального пользователя
- Избегает паттернов бота

### 2. Обработка rate limits
```python
if "429" in str(e):
    logger.warning("Rate limit hit")
```
- Логирует 429 ошибки
- Помогает понять когда Instagram блокирует

### 3. Отслеживание обработанных URL
```python
processed_instagram.json  # Не обрабатываем дважды
```

## 🚨 Признаки приближающейся блокировки

```
WARNING: Rate limit hit (429)
WARNING: General metadata extraction failed
ERROR: Unable to download webpage
ERROR: 403 Forbidden
```

**Что делать:**
1. Стоп на 1-24 часа
2. Проверь 2FA в Instagram браузере
3. Убедись что логин работает
4. Перезапусти

---

## 🎯 Рекомендации для частых запусков

### Безопасный режим (3-5 видео/день)
```bash
# Каждые 6 часов (4 запуска в день)
schedule: cron '0 */6 * * *'
# На каждый запуск 1-2 видео
```

### Если нужно больше
1. **Используй разные аккаунты** для разных источников
2. **Добавь случайные интервалы** между запусками (сейчас 2-5 мин)
3. **Мониторь логи** на 429 ошибки
4. **Будь готов паузе** на 24 часа если заблокируют

---

## 📈 Масштабирование

Если нужно 50+ видео/день:
1. Расстави запуски на разные часы
2. Используй разные Instagram аккаунты (рекомендовано)
3. Добавь прокси (усложнит setup)
4. Увеличь delays до 5-10 минут

---

## 🔍 Мониторинг

Проверяй GitHub Actions логи на:
- ✅ `✅ Got Instagram info` — успешно
- ⚠️ `Rate limit hit (429)` — нужна пауза
- ❌ `429 Forbidden` — Instagram заблокировал
- ❌ `locked behind login` — 2FA сработала

| Параметр | Значение |
