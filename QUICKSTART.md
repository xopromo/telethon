# 🚀 Instagram Agent — Запуск в один клик!

## Mac/Linux

1. **Двойной клик** на файл `run.sh`
   - Или в терминале: `bash run.sh`

2. **Введи Instagram ссылку** когда спросит:
   ```
   🔗 Введи Instagram ссылку (или Enter для мониторинга канала): https://www.instagram.com/p/ABC123/
   ```

3. **Жди результата** 🎉
   - Видео загружается в Saved Messages

---

## Windows

1. **Двойной клик** на файл `run.bat`
   - Откроется окно с меню

2. **Введи Instagram ссылку**:
   ```
   🔗 Введи Instagram ссылку (или Enter для мониторинга канала): https://www.instagram.com/p/ABC123/
   ```

3. **Жди результата** 🎉

---

## Что происходит

```
Нажал запуск
    ↓
Проверка Python и зависимостей (автоматически)
    ↓
Спрашивает Instagram ссылку
    ↓
Загружает видео + переписывает описание
    ↓
Отправляет в Saved Messages
    ↓
Готово!
```

---

## ✅ Требования

- **Python 3.8+** установлен
- **Залогинен в Instagram** в браузере
- **2FA отключена** в Instagram (временно)
- **.env файл** заполнен (Telegram API, AI ключи)

> Проверь что `.env` есть в папке проекта!

---

## 🆘 Не работает?

**На Mac/Linux:**
```bash
chmod +x run.sh    # Дать права на запуск
bash run.sh        # Запустить из терминала
```

**На Windows:**
- Нажми `Win + R`
- Напиши: `powershell -ExecutionPolicy Bypass -File run.bat`
- Нажми Enter

## Два режима

### 📌 Скачать одно видео
```
Введи ссылку: https://www.instagram.com/p/DYpsm93IVGM/

```

### 📡 Мониторить канал (просто нажми Enter)
```
Введи ссылку: [Enter без текста]
→ Обрабатывает все ссылки из Telegram канала
```
